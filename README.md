# ⚗️ Acid–Base Titration Virtual Laboratory

Run an acid–base titration on screen: choose the acid or base, set concentrations and volumes,
add titrant and watch the pH and indicator colour change.

- 🧪 Titration Simulator: live pH, flask colour and curve marker
- 📊 Titration Data Report: key results, full data table (CSV) and indicator suitability
- 📈 Curve Analysis: derivative curve, buffer region and comparison with other analytes
- 📄 PDF report with the titration curve and data, plus a quiz

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
